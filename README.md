# Water Emissions Analysis in Denmark (2008–2024)

## About the Project
This is my first beginner data analysis project, focused on exploring recorded water emissions in Denmark from 2008 to 2024. The project uses Python to analyse emission trends and understand the contribution of different pollutants over time.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Project Files
- **Water_Emissions_Analysis.ipynb** – Python notebook containing the data processing, analysis and visualisations.
- **graphs/** – Contains the three visualisations generated from the analysis.
- **Water_Emissions_Report.pdf** – Detailed project report covering the objectives, methodology, analysis and findings.

## Visualisations
- **Annual Total Emissions:** Shows how total recorded emissions changed across the years.
- **Emissions by Pollutant:** Compares the contribution of different pollutants each year.
- **Pollutant Trends:** Shows how pollutant contributions changed over time.

## Data Source
European Environment Agency (EEA) – Waterbase: Emissions (2026).

[View Dataset](https://www.eea.europa.eu/en/datahub/datahubitem-view/5bd950b1-52b9-42f3-b0d7-bf51ff3056b7)
